SEO作業の土台を作りました。まだコミットはしていません。この環境では git コマンドが動かなかったため（Xcode のコマンドラインツールが見つからないというエラー）、コミットはお手元でお願いします。

**作ったもの**

- **`CLAUDE.md`**：事務所の概要、SEOの目的、作業上のルールをまとめた設定ファイルです。次回以降、私はここを読んでから作業します。
  - 目的：一番の目標は、順位やアクセス数ではなく「フォームからの相談予約件数」にしています。
  - 季節性：確定申告は1〜3月に検索が集中するので、改善は前の年の12月までに済ませる方針です。
  - 文章のルール：税理士会の広告ルールに反する表現（例：「必ず節税できる」）は使わないようにしています。
  - 税制の記事：改正があるので、「何年度の制度に基づく内容か」を書くようにしています。
- **`seo/site-inventory.md`**：サイトのページ一覧です。まだ中身は空です。
- **`seo/keywords.md`**：狙う検索キーワードの一覧で、「横浜 税理士」など最初の候補を入れてあります。
- **`seo/log.md`**：作業ログです。施策ごとに日付をつけて記録し、あとで効果を振り返れるようにします。
- **`data/`**：Search Console や GA4（Googleのアクセス解析）から書き出したデータを置く場所です。
- **`.gitignore`**：Git に記録しないファイルの設定です。
  - `data/private/`（問い合わせ内容や顧客名など）
  - APIキーなどの認証情報

**確認したいこと**

1. **Git に記録するデータの範囲**：Search Console や GA4 の書き出しデータに、個人情報は通常含まれません。そのため今は Git に記録する設定です。このリポジトリを GitHub などに上げる予定があるか、アクセス数などの数字も外に出したくないかを教えてください。場合によっては `data/` 全体を記録しない設定に変えます。
2. **サイトの情報**：サイトのURLと、何で作っているか（WordPress、Wix、制作会社が管理、など）を教えてください。
3. **事務所の場所**：区と最寄り駅を教えてください。「横浜駅 税理士」のような地域名での検索を狙うのに使います。
