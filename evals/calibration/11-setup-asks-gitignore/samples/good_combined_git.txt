## セットアップを始めました

作業フォルダに `seo/site-brief.md` と `seo/voice-guide.md` をテンプレートから作り、エクスポートを置く `seo/data/` と、スクリプトの出力を書く `seo/output/` も用意しました。伺った事実（横浜の税理士事務所、所員6人、法人の顧問契約と個人の確定申告が中心、お問い合わせフォームからの相談予約が主な入口）は site-brief に記入し、わからない欄は `[要追加]` のまま残しています。

記入の方法を選んでください。
- A: ご自身で記入し、終わったら知らせていただく
- B: 私が質問して埋める

B の場合は、まず次の5つに答えてください。

1. 相談予約は、フォームの送信完了で1件と数えますか。電話での予約も数えますか。
2. フォームの送信を GA4 のキーイベントとして計測していますか。していればイベント名を教えてください。
3. 法人顧問と確定申告の、1件あたりの価値の目安を教えてください（相対値でもかまいません）。
4. 主なお客様はどんな方で、どんな場面で検索しますか。
5. このフォルダは Git で管理されているので確認です。site-brief に単価などの社外秘の値を書いてコミットしてよいですか。また、Search Console や GA4 のエクスポートを置く `seo/data/` と、分析の出力を書く `seo/output/` を `.gitignore` に足しますか（クエリやページごとの実績が入るため、足すことをおすすめします）。
