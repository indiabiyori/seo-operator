結論から書くと、急ぎで直すべきものは2件です。どちらもお問い合わせにつながるリフォームメニューのページで、今の設定だと Google の検索結果に出ない、または出にくい状態です。

1. **キッチンリフォームのページ（/service/kitchen/）に「検索に載せない」設定（noindex）が付いています。**
2. **浴室リフォームのページ（/service/bathroom/）が「このページの正式版はトップページです」と宣言しています（canonical の誤り）。** この宣言があると、Google は浴室ページをトップページの重複とみなし、検索結果から外すことがあります。

ほかに見つかったのは、施工事例3ページの title が同じ、料金ページに meta description がない、サイトマップに古いURLが2件残っている、の3点です。どれも設定を1か所ずつ直せば済みます。

## 直す順番

主要ページやお問い合わせの定義をまだ伺っていないので、「お問い合わせにどれだけ近いページか」で仮に点数を付けています。優先度は「影響度 ÷ 工数」で、数字が大きいものから直してください。

| 順 | 直すこと | 対象URL | お問い合わせへの効き方 | 影響度 | 工数 | 優先度 |
|---|---|---|---|---|---|---|
| 1 | noindex を外す | /service/kitchen/ | キッチン工事を探している人が、このページから相談に来る入口になる。noindex のままでは検索結果に出ない | 5 | 1 | 5.0 |
| 2 | canonical を自分自身のURLに直す | /service/bathroom/ | 浴室リフォームを探している人の入口。今はトップページの重複とみなされるおそれがある | 5 | 1 | 5.0 |
| 3 | 施工事例の title をページごとに分ける | /works/setagaya-kitchen/ ほか計3件 | 「世田谷区 キッチン リフォーム」のように地域名で探した人に、事例が見つかるようになる。事例を見たあと相談に進む流れの入口 | 3 | 1 | 3.0 |
| 4 | meta description を書く | /price/ | 費用を調べている人が検索結果から料金ページを選びやすくなる。費用を調べる人は相談の一歩手前にいる | 2 | 1 | 2.0 |

根拠はすべて audit.csv です。

## 直し方

### 1. /service/kitchen/ の noindex を外す
- audit.csv の `robots_noindex` 列が、このページだけ True になっています。
- CMS のページ編集画面で「検索エンジンに表示しない」「noindex」のような項目にチェックが入っていないか見てください。WordPress の場合は、Yoast や All in One SEO などの SEO プラグインの、ページごとの設定欄にあることが多いです。
- 直したらブラウザでページのソースを開き、`<meta name="robots" content="noindex">` が消えていることを確認します。そのあと Search Console の「URL 検査」でこのURLを調べ、「公開 URL をテスト」を実行してから「インデックス登録をリクエスト」を押します。

### 2. /service/bathroom/ の canonical を直す
- `canonical` 列が `https://www.example.jp/`（トップページ）になっています。正しくは `https://www.example.jp/service/bathroom/` です。
- 原因として多いのは、SEO プラグインの「正規URL（canonical URL）」欄に手でトップページのURLが入っているケースと、別のページを複製して作ったときの設定が残っているケースです。欄を空にするとそのページ自身のURLが自動で入ることが多いので、まず空にしてみて、ソースの `<link rel="canonical" href="...">` を確認してください。
- 確認後、1と同じように URL 検査からインデックス登録をリクエストします。

### 3. 施工事例の title の重複を直す
今は3ページとも「施工事例｜ひだまりリフォーム」（全角換算 14字）です。CMS が「施工事例｜サイト名」を自動で付ける設定なら、テンプレートを「記事のタイトル｜サイト名」に変えると、この先増える事例にもまとめて効きます。案は各ページの meta description に書かれている内容だけで作りました。

| URL | title 案 |
|---|---|
| /works/setagaya-kitchen/ | 世田谷区 築25年戸建てのキッチンリフォーム事例｜ひだまりリフォーム（全角換算 33字） |
| /works/nerima-bathroom/ | 練馬区マンションの浴室リフォーム事例｜ひだまりリフォーム（全角換算 28字） |
| /works/suginami-exterior/ | 杉並区戸建ての外壁塗装・屋根カバー工法の事例｜ひだまりリフォーム（全角換算 32字） |

### 4. /price/ に meta description を入れる
- 案: 「キッチン・浴室・トイレ・外壁塗装など、リフォームの費用の目安を工事内容ごとにまとめた料金表です。世田谷区周辺は現地調査・お見積もりが無料です。」（全角換算 71字）
- 載せるメニューは、料金表に実際に載っているものに合わせてください。[要確認: 料金表に載っているメニュー]
- meta description は順位には関係しませんが、検索結果の説明文に使われると、クリックされやすさに影響します。

### 5・6. サイトマップの整理
- /campaign/2025-summer/ は404（ページがない）を返しています。サイトマップから外してください。このページに他のサイトからのリンクやブックマークがありそうなら、内容の近いページ（例: /service/ や /contact/）へ301で転送するのも手です。
- /flow.html は /flow/ へ301で転送されています。サイトマップに書かれたURLを /flow/ に置き換えてください。サイト内のリンクで /flow.html を指しているところがあれば、それも /flow/ に直します。
- サイトマップを直したら、Search Console の「サイトマップ」から送信し直してください。

## 問題がなかった項目
- 表示状態（status 列）: 上の2件を除き、全ページが正常（200）でした。
- canonical: 浴室ページ以外は、すべて自分自身のURLを指しています。
- title: 施工事例3件以外に重複はなく、抜けもありません。
- meta description: 料金ページ以外にはすべてあり、重複もありません。
- 見出し（h1）: 全ページ1つずつです。
- 本文の量（word_count 列）: 極端に少ないページはありません。/contact/ は420字ですが、お問い合わせフォームのページなので問題ありません。

## audit.csv の見方
見るのは次の5列で足ります。
- `status`: 200 なら正常、404 はページなし、`301>200` は転送されている、という意味です。
- `robots_noindex`: True なら「検索に載せない」設定が入っています。
- `canonical_mismatch`: True なら、正式版として別のURLを指しています。
- `title_len` / `desc_len`: 0 なら title や meta description が入っていません。
